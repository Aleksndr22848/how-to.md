# Как сгенерировать QR-код для ссылки

## Предусловия
Перед началом работы убедитесь, что:
* В вашей системе установлен Node.js (рекомендуется версия 18 или выше).
* Репозиторий React Mini Projects склонирован на компьютер.
* Выполнена установка npm-зависимостей (в терминале выполнена команда `npm install`).
* Локальный сервер разработки запущен.

## Шаги
1. Откройте браузер и перейдите на локальный адрес `http://localhost:5173/`.
2. На главной странице прокрутите список проектов и найдите раздел **"QR Code Generator"**.
3. Кликните на карточку "QR Code Generator" для перехода к проекту.
4. В поле ввода в верхней части страницы введите любой текст или ссылку (например, `https://github.com/`).
5. Установите желаемый размер QR-кода с помощью ползунка или выпадающего списка (если он предусмотрен интерфейсом).

## Результат
Под полем ввода появится сгенерированное черно-белое изображение QR-кода, соответствующее введенному тексту или ссылке. При изменении входного текста картинка обновится автоматически.
